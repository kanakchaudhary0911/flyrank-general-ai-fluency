# Draw the Path – Portfolio Sitemap & Toolkit

## Assignment Overview

This assignment focused on defining the structure and direction of my professional portfolio before beginning development. The objective was to identify one clear technical claim, one specific hiring audience, and one primary action my portfolio should encourage.

Using AI-assisted discussions and portfolio planning exercises, I refined my portfolio strategy, created a visual sitemap, and established a structured foundation for future portfolio development.

---

## Objectives

- Define one primary technical claim.
- Identify one specific hiring audience.
- Choose one primary portfolio action.
- Create a clear portfolio sitemap.
- Validate portfolio direction through AI-assisted discussions.

---

## Deliverables

- Portfolio Sitemap (PDF)

- Portfolio Strategy Validation
- AI Recommendations

## Learning Outcomes

Through this assignment, I learned how to:
