# FL-01: AI Workflow Audit and Tool Setup

## Assignment Overview

This assignment focuses on understanding my personal workflow and identifying how Artificial Intelligence can be integrated effectively into my daily academic and development tasks.

The objective was to evaluate recurring activities, determine the appropriate level of AI collaboration for each task, configure essential AI tools, and establish a structured workflow for future assignments.

---

## Objectives

- Audit recurring weekly tasks.
- Classify tasks using AI collaboration strategies.
- Configure essential AI tools and accounts.
- Create a Claude Project with custom instructions.
- Define measurable success criteria for future AI-assisted work.
