# Week 3 – Portfolio System

This folder contains Week 3 work for the FlyRank General AI Fluency program. The week focuses on portfolio consistency, identity, image curation, and the content/CTA system.

## Assignments

| Folder | Focus |
|---|---|
| `01_Consistency-Not-Talent-and-Frame-Not-Upstage` | Consistency and keeping design in service of the work |
| `02_Decide-Once-Build-Your-Identity-Kit` | Identity kit, style guide, and logo |
| `03_Kill-Your-Darlings-Curate-Your-Images` | Curating portfolio images and documenting rejected choices |
| `04_The-Through-Line-Map-Content-and-CTAs` | Mapping content, claims, and calls to action |

Each assignment keeps its own supporting notes, screenshots, and assets.
