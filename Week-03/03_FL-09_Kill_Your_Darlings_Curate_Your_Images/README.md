## Real Capture vs AI
I chose real screenshots for all project-specific visuals because these images need to prove the work itself. AI-generated stand-ins could look polished but would not accurately demonstrate the implemented interface.

For actual project evidence, I preferred real captures over AI-generated images.

## Curation
I kept only screenshots that clearly communicate the projects and removed the temptation to use decorative visuals that do not add proof. The final set is intentionally focused on evidence, legibility, and relevance.
