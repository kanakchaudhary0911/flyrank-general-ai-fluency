# Decide Once — Build Your Identity Kit

## Assignment Overview

This assignment focused on creating a consistent visual identity for my professional portfolio before continuing with the portfolio build.

The objective was to make a small set of design decisions once and apply them consistently across future pages, case studies, project sections, and supporting materials.

The identity was intentionally kept minimal so that the portfolio's projects, case studies, screenshots, and technical proof remain the primary focus.

---

## Objectives

- Define a consistent visual direction for the portfolio.
- Select one or two fonts for consistent typography.
- Create a limited and reusable color palette.
- Design a simple personal logo/monogram.
- Create reusable visual identity guidelines.
- Establish design decisions that can be applied consistently across future portfolio pages.

---

## Final Identity

### Visual Direction

**Minimal · Calm · Modern · Professional**

The portfolio uses a soft lavender/purple visual identity combined with near-black typography and an off-white background.

The overall approach is intentionally clean and understated rather than highly decorative.

---

## Typography

### Heading Font

**Playfair Display**

Used for:

- Main headings
- Section titles
- Important visual statements
- Major project titles

### Body Font

**Inter**

Used for:

- Body text
- Navigation
- Buttons
- Labels
- Project descriptions
- Supporting information

---

## Color Palette

| Role | Color | Hex |
|---|---|---|
| Primary | Lavender Purple | `#8B6FC7` |
| Text | Near-Black | `#17151F` |
| Background | Soft Off-White | `#FAF8FC` |
| Accent | Soft Violet | `#B89AE8` |

The palette is intentionally limited to four colors to maintain visual consistency and readability across the portfolio.

---

## Logo

The portfolio uses a simple **KC monogram**, representing:

- **K** — Kanak
- **C** — Chaudhary

The logo is designed to work across the portfolio, favicon, project documentation, and other personal branding surfaces.
