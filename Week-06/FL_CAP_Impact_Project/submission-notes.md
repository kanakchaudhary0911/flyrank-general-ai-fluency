# Submission Notes

This capstone establishes a repeatable process for adding future portfolio case studies.

The next named piece of work is the **Personal AI Agent**.

Each future case study will follow the same three-beat structure:

**Problem → What I Did → What Came of It**

The process includes documenting the problem, describing the implementation and use of AI/tools, recording the result and lessons learned, and then adding the finished case study to the portfolio.

The existing **"Kanak Portfolio Build"** Claude Project is being preserved as the build context for future portfolio updates. It can be reused to maintain consistency in portfolio voice, stack, identity, and project context.
