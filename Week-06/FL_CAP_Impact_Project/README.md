# General AI Fluency · Impact Project

## How I Will Add My Next Case Study

I will add each new portfolio case study using the three-beat structure from Week 2:

1. **Problem** — Explain the real problem or need that the project was created to solve.
2. **What I Did** — Describe my approach, technologies and tools used, and where AI helped during the build.
3. **What Came of It** — Explain the result, what worked, what I learned, and any measurable or visible outcome.

## Process

1. Finish and test the project.
2. Identify the main problem it solves.
3. Write the **Problem**, **What I Did**, and **What Came of It** sections.
4. Add relevant screenshots, demo links, or other evidence.
5. Add the case study to the Projects/Case Studies section of my portfolio.
6. Review the case study using my existing Claude Project so the writing stays consistent with my portfolio voice, stack, and identity.
7. Check that all links work and that a recruiter or visitor can understand the case study quickly.
