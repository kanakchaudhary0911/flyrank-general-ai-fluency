# FL_CAP_Impact_Project — General AI Fluency Capstone

## Capstone Overview

This project is my **General AI Fluency Capstone Project** for the FlyRank AI Internship Program.

The capstone focuses on improving my personal portfolio workflow by establishing a repeatable process for turning future projects into clear, evidence-based portfolio case studies.

The core approach uses the three-beat case study structure developed during Week 2:

1. **Problem** — Explain the real problem or need the project was created to solve.
2. **What I Did** — Describe the approach, technologies, tools used, and where AI helped during the build.
3. **What Came of It** — Explain the result, what worked, what was learned, and any measurable or visible outcome.

The project also demonstrates how AI tools can be incorporated into an ongoing development workflow without rebuilding the existing portfolio context from scratch.

## Case Study Structure

Every new case study will follow the same three-beat structure.

**01 — Problem**

Explain:

- What problem the project solves
- Who or what the project is intended to help
- Why the project was worth building

**02 — What I Did**

Document:

- My approach
- Technologies used
- Tools used
- Where AI assisted the development process
- Important implementation decisions

**03 — What Came of It**

Explain:

- What was built
- What worked
- What broke or required iteration
- What I learned
- Any measurable or visible outcome
- Evidence supporting the result

This structure keeps the case study focused on both the work and the outcome, rather than only describing the final project.

## Process

The complete case study workflow is:

**Step 1 — Finish and Test the Project**

Complete the project and verify that the implementation works as intended.

**Step 2 — Identify the Main Problem**

Define the real problem or need addressed by the project.

**Step 3 — Document What I Did**

Describe the implementation approach, technologies, tools, and AI assistance.

**Step 4 — Document What Came of It**

Record the result, successful parts, problems encountered, lessons learned, and visible outcomes.

**Step 5 — Add Evidence**

Attach relevant:

- Screenshots
- Demo links
- Repository links
- Other supporting evidence

**Step 6 — Add the Case Study**

Add the completed case study to the Projects / Case Studies section of the portfolio.

**Step 7 — Review with Claude**

Use the existing "Kanak Portfolio Build" Claude Project to keep the case study consistent with the portfolio voice, stack, identity, and existing project context.

**Step 8 — Final Review**

Check:

- All links work
- The project is understandable
- The case study is easy to scan
- The evidence supports the claims
- The writing remains consistent with the portfolio
