# FL-06: Prompting Fundamentals on Real Tasks

## Assignment Overview

This assignment focused on improving prompt quality through iterative prompt engineering on a real task identified during my AI workflow audit. Instead of relying on a single prompt, I refined it step by step using different prompting techniques and compared how each change affected the AI's output.

The objective was to understand how structured prompting improves response quality and to create a reusable prompt template that can be applied to future projects.

---

## Objectives

- Apply prompt engineering techniques to a real task.
- Improve a prompt through multiple iterations.
- Compare outputs after each refinement.
- Compare the final prompt across Claude and ChatGPT.
- Create a reusable prompt template.
