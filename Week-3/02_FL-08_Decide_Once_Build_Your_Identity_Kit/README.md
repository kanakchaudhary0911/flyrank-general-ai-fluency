## Objective

The objective was to create a simple and consistent portfolio identity consisting of:

- One or two fonts
- A limited color palette
- A simple logo/monogram
- A reusable style guide
- A clear visual direction for future portfolio pages

The design is intentionally restrained so that the portfolio's projects, case studies, screenshots, and technical proof remain the main focus.

---

## Final Identity

### Visual Direction

**Minimal · Calm · Modern · Professional**

The portfolio uses a soft lavender/purple visual identity combined with near-black typography and an off-white background.

The overall approach is intentionally clean and understated rather than highly decorative.

---

## Typography

### Heading Font

**Playfair Display**

Used for:

- Main headings
- Section titles
- Important visual statements
- Major project titles

### Body Font

**Inter**

Used for:

- Body text
- Navigation
- Buttons
- Labels
- Project descriptions
- Supporting information

## Color Palette

| Role | Color | Hex |
|---|---|---|
| Primary | Lavender Purple | `#8B6FC7` |
| Text | Near-Black | `#17151F` |
| Background | Soft Off-White | `#FAF8FC` |
| Accent | Soft Violet | `#B89AE8` |

The palette is limited to four colors to maintain visual consistency and readability.

## Logo

The portfolio uses a simple **KC monogram**, representing:

- **K** — Kanak
- **C** — Chaudhary

The logo is designed to work across the portfolio, favicon, project documentation, and other personal branding surfaces.
