# Empty but Live: Ship a Blank Page

## Assignment Overview

This assignment focused on creating a near-blank portfolio project, deploying it to Netlify, and confirming that the live page is accessible from a second device.

The purpose was to establish a working public deployment before beginning the full portfolio build.

---

## Objectives

- Create a near-blank portfolio project.
- Create the initial `index.html` homepage.
- Deploy the project to Netlify.
- Confirm that the deployed page is publicly accessible.
- Verify the live page from a second device.
- Prepare the AI workspace for the next portfolio build phase.
