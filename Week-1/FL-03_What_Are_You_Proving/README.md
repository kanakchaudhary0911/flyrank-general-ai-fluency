# FL-03: What Are You Proving?

## Assignment Overview

This assignment focused on defining the core purpose of my professional portfolio before building it. Through a structured AI-guided interview, I refined my portfolio positioning by identifying one primary technical claim, one specific hiring audience, and one clear action I want visitors to take.

The objective was to move beyond generic portfolio descriptions and build a portfolio supported by clear technical reasoning, evidence, and deliberate engineering decisions.

---

## Objectives

- Define one primary technical claim.
- Identify one specific hiring audience.
- Choose one primary portfolio action.
- Validate technical claims through AI-guided questioning.
- Build a proof statement based on evidence rather than assumptions.

---

## Deliverables

- Primary Action Definition

## Learning Outcomes

Through this assignment, I learned how to:

- Define a single technical claim supported by evidence.
- Explain technical decisions using clear reasoning and tradeoffs.
- Identify the right audience for my portfolio.
- Structure a proof statement around verifiable artifacts instead of generic claims.
- Use AI as a critical thinking partner to refine ideas through iterative questioning.
