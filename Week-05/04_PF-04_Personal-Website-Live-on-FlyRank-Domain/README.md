### File Responsibilities

**`index.html`**

- Contains the complete portfolio structure and content.
- Defines navigation, sections, project information, skills, and contact links.

**`style.css`**

- Controls the visual design, typography, spacing, layout, responsive behavior, and overall portfolio appearance.

**`script.js`**

- Reserved for client-side interactions.
- The current portfolio does not require JavaScript functionality, so the file remains intentionally minimal.

**`assets/`**

- Contains supporting portfolio assets.
- Includes the resume PDF used by the website.

**`DNS-Walkthrough.md`**

- Documents DNS, CNAME records, resolvers, nameservers, DNS responses, and the process of reaching the hosted website.

---

## Deployment

- The website was deployed using Netlify Drop.
- The project folder containing `index.html`, `style.css`, `script.js`, and `assets/` was uploaded to Netlify.
- After deployment, the generated site name was changed to `kanak-chaudhary`.
- The resulting public URL is `https://kanak-chaudhary.netlify.app`.
- The site was also configured as publicly accessible so that it can be viewed without requiring access to the Netlify account.

---

## DNS Understanding

The DNS walkthrough is documented separately in `DNS-Walkthrough.md`.

It explains:

- What DNS does
- What a CNAME record is
- The role of DNS resolvers
- The role of nameservers
- How DNS records are resolved
- How a browser reaches the hosting platform
- How HTTPS delivers the final website
