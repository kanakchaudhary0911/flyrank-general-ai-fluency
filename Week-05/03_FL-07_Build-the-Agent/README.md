# FL-07 — Build the Agent

## Assignment Overview

This assignment is the implementation stage of the personal AI agent designed in FL-06: the **AI Project & Career Research Assistant**.

## Focus

- Implement the agent behavior defined in FL-06.
- Use connected information sources where required.
- Keep outputs grounded in available evidence.
- Test project, skill-gap, evidence, and action-planning scenarios.
- Evaluate failures and refine the agent behavior.

## Guardrails

The agent should avoid fabricated skills, projects, achievements, or unsupported claims and should communicate uncertainty when evidence is incomplete.
