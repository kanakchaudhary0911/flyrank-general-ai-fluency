# Case Study 1 — FlyRank AI Engineering Portfolio

## The Problem

My internship work was scattered across different files and folders, making it difficult to present my progress in a clear and organized way. I wanted one professional GitHub repository that documented my learning journey and weekly assignments.

## What I Did and Decided

- Created a structured GitHub repository organized week by week.
- Maintained separate folders for assignments, screenshots, documentation, and supporting files.
- Wrote consistent README files for every assignment.
- Used Git, GitHub, Claude AI, and ChatGPT to improve documentation and portfolio planning.
- Included only completed and properly documented work.

## What Came of It

The repository became a well-organized record of my AI Fluency internship work, making it easier to review assignments, showcase technical documentation, and continue adding future projects.

**What I'd Do Differently**

Plan the complete repository structure before adding files and continue improving documentation as new projects are added.

# Case Study 2 — AI Internship Landing Page

## The Problem

I wanted to build a responsive landing page that clearly explained an AI internship program while improving my frontend development and responsive design skills.

## What I Did and Decided

- Built the landing page using HTML5, CSS3, and JavaScript.
- Designed sections including the hero banner, program overview, features, benefits, application process, FAQs, and contact information.
- Focused on responsive layouts and a simple navigation experience.
- Kept the interface clean by avoiding unnecessary animations and distractions.
- Published the source code on GitHub as part of my portfolio.

## What Came of It

The finished project is a responsive landing page that demonstrates my frontend development skills, layout planning, and responsive design approach.

**What I'd Do Differently**

Improve the UI further, add meaningful interactive features, optimize performance, improve accessibility, and deploy future versions with live demonstrations.
