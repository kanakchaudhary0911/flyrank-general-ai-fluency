## Key Prompting Principles

### 1. Clear Instructions

Prompts should clearly explain what the AI needs to do.

### 2. Context

Providing relevant background information helps the AI understand the task correctly.

### 3. Specificity

Specific requirements reduce ambiguity and improve the usefulness of the response.

### 4. Constraints

Adding constraints such as format, length, audience, or required sections helps control the output.

### 5. Examples

Providing examples can help communicate the expected structure or style of the response.

### 6. Iteration

Prompts can be refined based on the quality of the generated output.

---

## Approach

The task was completed using an iterative prompting process:

1. Start with a basic prompt.
2. Review the generated output.
3. Identify missing context or unclear instructions.
4. Improve the prompt by adding relevant details.
5. Generate the response again.
6. Compare the results.
7. Refine the prompt until the output better matches the task requirements.

## Conclusion

This assignment demonstrated that better AI outputs depend heavily on the quality of the instructions provided. Clear context, specific requirements, constraints, and iterative refinement make prompts more reliable and useful for real-world tasks.

The exercise helped establish a practical foundation for using AI as an effective development and productivity assistant.
