# The Prompt Ladder

## Assignment Overview

This assignment focused on improving AI prompt quality through an iterative prompt engineering process. Starting with a weak baseline prompt, I refined it one step at a time by adding a single improvement layer in each version and comparing the resulting outputs.

The objective was to understand how individual prompt components influence AI-generated responses and to create a reusable prompt that produces accurate, structured, and reliable results.

---

## Objectives

- Create a weak baseline prompt.
- Improve the prompt through five iterative versions.
- Add only one prompt engineering layer per version.
- Compare outputs after each iteration.
- Build a final reusable prompt based on the lessons learned.
